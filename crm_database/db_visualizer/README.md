# db_visualizer (Optional Helper)

This is an optional Node-based database viewer. It is NOT part of the database container runtime.

How to run locally:
1) cd secure-crm-platform-40906-40916/crm_database/db_visualizer
2) source postgres.env
3) npm install
4) npm run start

If you encounter Node/Express errors, ensure you run this outside of the database container, and that you have Node 18+ installed on your host or a separate tools container.
